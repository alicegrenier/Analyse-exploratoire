# **TP 1 : Analyse exploratoire de données**
Dans le cadre de ce TP, nous nous intéressons à la problématique de la prédiction de revenus à partir de données socio-démographiques. Le jeu de données utilisé est ACISIncome pour l’état de Californie. La tâche est une classification binaire : prédire si le revenu annuel d’un individu actif est supérieur à 50 000 dollars. Le présent rapport permet de rendre compte des expérimentations effectuées.
